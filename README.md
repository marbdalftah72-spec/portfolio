## 📂 Featured Repositories Showcased

The portfolio links directly to verifiable, open-source engineering implementations across multiple domains:

### 🤖 1. Artificial Intelligence & Deep Learning
* [**Neural-Network (Structural Health Monitoring)**](https://github.com/marbdalftah72-spec/Neural-Network): Comparative deep learning benchmark for concrete crack classification (>40,000 images) evaluating FFNN, BiLSTM, Custom CNN, and MobileNetV2 (**>99% ROC-AUC**).
* [**ML-task (Advanced Machine Learning & RL Suite)**](https://github.com/marbdalftah72-spec/ML-task): Supervised churn benchmarking, tabular Q-learning with Bellman optimality, and Deep Q-Networks (DQN) with experience replay.
* [**CNN (Digital Image Processing & Defect Profiling)**](https://github.com/marbdalftah72-spec/CNN): Modular 6-stage computer vision suite covering 2D Fast Fourier Transform (FFT), spatial convolution kernels, CLAHE, and morphological defect profiling.
* [**AI-Search-Algorithms-Pathfinding**](https://github.com/marbdalftah72-spec/AI-Search-Algorithms-Pathfinding): State-space search architectures comparing Uninformed (BFS, DFS, UCS) and Heuristic (Greedy, A* Search) algorithms.
* [**Statistical-Data-Analysis-Python**](https://github.com/marbdalftah72-spec/Statistical-Data-Analysis-Python): Statistical hypothesis testing, parametric/non-parametric tests, and distribution analysis on Kaggle datasets.

### 💻 2. Computer Architecture & Low-Level Hardware
* [**16bit-Basic-Computer-Hardwired-CPU**](https://github.com/marbdalftah72-spec/16bit-Basic-Computer-Hardwired-CPU): Complete general-purpose 16-bit processor built from fundamental gates in Logisim Evolution, featuring Register Data Unit, 16-bit ALU, Common Bus, and Hardwired Control Unit (HCU).
* [**Analog-Electronics-Summing-Amplifier**](https://github.com/marbdalftah72-spec/Analog-Electronics-Summing-Amplifier): Operational amplifier analog circuit for dual-sign voltage addition and CMRR verification.

### 🏢 3. Enterprise Software, Networking & Embedded Systems
* [**Supermarket-Management-System-CPP**](https://github.com/marbdalftah72-spec/Supermarket-Management-System-CPP): Modular POS and inventory ledger system with strict OOP, custom data structures, and persistent file storage.
* [**Pharmacy-Management-System-CPP**](https://github.com/marbdalftah72-spec/Pharmacy-Management-System-CPP): Healthcare dispensary system with FIFO batch tracking, prescription checks, and allergy verification.
* [**Enterprise-Network-Design-Cisco-Packet-Tracer**](https://github.com/marbdalftah72-spec/Enterprise-Network-Design-Cisco-Packet-Tracer): 3-tier hierarchical enterprise network with OSPFv2, inter-VLAN routing, NAT, EtherChannel, and port security.
* [**Automatic-Sensor-Gate-Embedded-System**](https://github.com/marbdalftah72-spec/Automatic-Sensor-Gate-Embedded-System): Automated gate barrier with ultrasonic distance profiling, PIR motion detection, and servo motor control.

## 💻 Local Development & Viewing

To run and preview the portfolio locally on your machine:

### Option A: Using Python built-in HTTP server
```bash
# Clone the repository
git clone https://github.com/marbdalftah72-spec/portfolio.git
cd portfolio

# Run a local web server
python -m http.server 8080
```
Then open your browser at `http://localhost:8080`.

### Option B: Direct File Open
You can open `index.html` or `presentation.html` directly in any modern browser (Chrome, Edge, Firefox, Safari).
